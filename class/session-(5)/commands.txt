in targeted mode;
when you change the Type and also SELinux_user and SELinux_role of a file you cant

/etc/selinux/targeted/contexts/files/file_context 

semanage fcontext -l

semanage fcontext -a -t ssh_home_t /etc/file # this will add the context for /etc/file in /etc/selinux/targeted/contexts/files/file_contexts.local
# you can also confirm it by:
semanage fcontext -l | grep /etc/file

# but the file currently doesnt have this context you set. to apply the new context on file do:
restorecon -v /etc/file
# this will read and set the new context from /etc/selinux/targeted/contexts/files

# you can re-assign the context by -m (modify) and then restorecon -v /etc/file to take effect
semanage fcontext -m -t admin_home_t /etc/file
restorecon -v /etc/file

# to remove the context from the file (the default context will be replace)
semanage fcontext -d -t admin_home_t /etc/file
restorecon -v /etc/file
