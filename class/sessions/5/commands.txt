NOTE:
in targeted mode;
when you change the Type and also SELinux_user and SELinux_role of a file you cant
restorecon the file back again normally; because restorecon restores only the type, not the 
user or role. for restoreing that it needs -F switch to force that.

/etc/selinux/targeted/contexts/files/file_context  # all files and dirs assigned with a selinux context

semanage fcontext -l

# this will add the context for /etc/file in /etc/selinux/targeted/contexts/files/file_contexts.local
semanage fcontext -a -t ssh_home_t /etc/file
note that the path to file has to be absolute durring the defining the context for the first time
# you can also confirm it by:
semanage fcontext -l | grep /etc/file

# but the file currently doesnt have this context you set. to apply the new context on file do:
restorecon -v /etc/file
# this will read and set the new context from /etc/selinux/targeted/contexts/files

# you can re-assign the context by -m (modify) and then restorecon -v /etc/file to take effect
semanage fcontext -m -t admin_home_t /etc/file
restorecon -v /etc/file

# to remove the context from the file (the default context will be replace)
semanage fcontext -d /etc/file
restorecon -v /etc/file

# add selinux label to a dir and everything underneath e.g /web dir
semanage fcontext -a -t httpd_sys_content_t "/web(/.*)?"
restorecon -Rv /web
