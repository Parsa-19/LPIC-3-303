execution permission depends on type of the file.
if the file is binary it is already compiled and doesnt need to be read and you only need to execute. 
thus binary files could be executed only by --x permission.
but bash scripts or python have Interpreter to exeute. they READ file and interprete it to machine code and then executes them.
thus these script files need r-x permission to be executed.

rm -rf a.txt  # not permitted 
chattr -a a.txt  # operations permitted now
